# charls_grip_strength_stroke
Python code for population-based cohort analysis. This study explores the association between relative grip strength and incident stroke using harmonized CHARLS data with Cox proportional hazards regression.
# grip strength to weight ratio and incident stroke: Evidence from CHARLS
This repository contains all analytical scripts for the population-based cohort study exploring the association between grip strength to weight ratio and incident stroke.

## Data source
China Health and Retirement Longitudinal Study (CHARLS) harmonized dataset.
Access to CHARLS data requires official application via the CHARLS platform.

## Analysis
- Study design: Prospective cohort study
- Statistical model: Cox proportional hazards regression
- Multiple imputation, mediation, interaction, subgroup analyses and sensitivity analyses are included.

## Software
Python 3.8 (lifelines, scikit-learn, statsmodels)
